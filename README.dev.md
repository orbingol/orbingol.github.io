# Local development

Astro + Tailwind. **Use Docker** — no host Node required. Images use **Node.js 24 LTS**; Astro telemetry is off (`ASTRO_TELEMETRY_DISABLED=1`).

## Prerequisites

- Docker Desktop (or another Docker engine with Compose)
- [uv](https://docs.astral.sh/uv/) — for lint / pre-commit (optional locally; used in CI)

## Start the dev server

```bash
docker compose up web
```

Open [http://localhost:4321](http://localhost:4321). The repo is bind-mounted, so edits hot-reload. Stop with `Ctrl+C`.

After `package.json` / lockfile changes:

```bash
docker compose build web && docker compose up web
```

## Production build locally

```bash
docker compose run --rm build
```

Output lands in `./dist` (gitignored — never commit it). CI-equivalent:

```bash
docker build -f docker/Dockerfile --target export --output type=local,dest=dist .
```

`public/` (e.g. `robots.txt`, `llms.txt`, favicons) is copied into `dist/` on build; sitemap is generated by `@astrojs/sitemap`; repo-root `CNAME` is copied by `npm run build`.

## Where to edit

| Path                        | Purpose                                           |
| --------------------------- | ------------------------------------------------- |
| `src/pages/`                | Routes (`/`, `/cv`, `/contact`, `/projects`, …)   |
| `src/components/`           | Nav, footer, cards, etc.                          |
| `src/layouts/Layout.astro`  | Shared shell, SEO head, GA, fonts                 |
| `src/lib/site.ts`           | Site name, default OG, `sameAs`, title helpers    |
| `src/content/projects/*.md` | Project pages (frontmatter + body)                |
| `src/styles/global.css`     | Design tokens / global CSS                        |
| `public/`                   | Static files, OG image, favicons                  |
| `CNAME`                     | Custom domain; copied into `dist/` on build       |

Add a project by copying an existing file under `src/content/projects/`. Use `enabled: false` for drafts
(omitted from nav, listings, routes, and sitemap). The `others` project uses `order: 999` so it sorts last.

## Favicons

Edit `public/favicon.svg` and/or `public/og-default.svg`, then:

```bash
docker compose run --rm favicons
```

Hard-refresh (or clear site data) after regenerating — browsers cache favicons aggressively.

## Docker targets

| Target          | Role                                         |
| --------------- | -------------------------------------------- |
| `web` (default) | `astro dev` for local preview                |
| `build`         | `astro build` → `/app/dist`                  |
| `export`        | Scratch stage used by CI to copy only `dist` |
| `favicons`      | Rasterize SVG sources → PNG/ICO under `public/` |

## Lint / pre-commit

```bash
uvx pre-commit run --all-files
```

Or install once: `uv tool install pre-commit`, then `pre-commit install` / `pre-commit run --all-files`.
CI runs the same checks via [`.github/workflows/pre-commit.yml`](.github/workflows/pre-commit.yml).

Format via the site Node toolchain:

```bash
docker compose run --rm web npm run format
docker compose run --rm web npm run format:check
```

## Deploy

Pushes to `master` run [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) (Docker build → GitHub Pages).
After the first successful run, set Pages source to **GitHub Actions** (Settings → Pages).
