NURBS-Python (**geomdl**) is a pure Python object-oriented B-spline and NURBS library with convenient data structures and extensible algorithms. The work is described in our [SoftwareX article](https://www.sciencedirect.com/science/article/pii/S2352711018301778).

## Features

- Self-contained, object-oriented, extensible, and highly customizable API
- Convenient data structures for storing curve, surface, and volume descriptions
- Surface and curve fitting with interpolation and least squares approximation
- Surface trimming
- Knot vector and surface grid generators
- Customizable visualization and animation with [Matplotlib](https://matplotlib.org/), [Plotly](https://plot.ly/python/), and [VTK](https://www.vtk.org/)
- Export to JSON, YAML, Libconfig, STL, OBJ, and VTK
- [Examples repository](https://github.com/orbingol/NURBS-Python_Examples) with dozens of usage and integration scripts
- Complete documentation with references, examples, and illustrations
- Pure Python implementation (no required C/C++ or Fortran dependencies); optional Cython build for higher performance
- Install from [PyPI](https://pypi.org/project/geomdl/) or [Conda](https://anaconda.org/orbingol/geomdl)
- Configurable [command-line application](https://nurbs-python.readthedocs.io/projects/cli)
- Common spline geometries via the [shapes](https://nurbs-python.readthedocs.io/projects/shapes) module
- Rhino `.3dm` import/export via [rw3dm](https://nurbs-python.readthedocs.io/en/latest/modules_rhino.html)
- [Docker images](https://hub.docker.com/r/idealabisu/nurbs-python/) available

See the [documentation](https://nurbs-python.readthedocs.io/) and [wiki](https://github.com/orbingol/NURBS-Python/wiki) for details.
